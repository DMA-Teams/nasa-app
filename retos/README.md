## ¿Cuál elijo?

- **Equipo sin programadores:** 1, 3, 13 o 14 con Google Stitch (Nivel 2) o Lovable (Nivel 3).
- **Equipo mixto:** 5, 7, 11 con Lovable o v0 + un dev que conecte la API de NASA.
- **Equipo técnico:** 2, 4, 6, 8, 9, 12 con Claude Code o Codex. Son los de mayor techo, pero el manejo de datos les va a costar horas.
- **Con impacto local fuerte en Honduras:** 7 (Corredor Seco), 9 (temporada de quemas), 6 (inundaciones en el Valle de Sula), 2 (lluvia Caribe vs. Corredor Seco).

## Estructura de cada ficha

1. Qué pide NASA (en corto)
2. Bájalo a una persona (persona · situación · dificultad · consecuencia)
3. Datos NASA que hacen de motor
4. Las 4 pantallas
5. Qué construir según tu equipo (cadete, Nivel 2, Nivel 3, dev)
6. Semilla para el prompt (rellénala y llévala a `prompts/`)
7. Trampas comunes
